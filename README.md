# 台南・冬の小旅行 2027

2027年1月28日（木）〜30日（土）、台南3日間・2泊の旅のしおり。自家用車での旅です。

- 日文為主、中文與英文為輔
- 純 HTML / CSS / JavaScript，不需要建置
- 所有行程資料集中在 `assets/js/data.js`
- 照片皆為 AI 生成示意圖（ChatGPT），轉成 WebP 兩種寬度
- 旅途模式：網址加上 `#travel`

## 檔案結構

```
index.html
assets/css/style.css
assets/js/data.js   全部行程資料
assets/js/app.js    互動功能
assets/fonts/       子集化字型（Noto Serif CJK JP、Yuji Boku、Newsreader）
assets/photos/      照片（大圖與 -s 小圖）
```

## 更新照片

換照片後把 `data.js` 裡的 `photoVer` 加一，瀏覽器才會載入新圖。

資料查證日期：2026年11月。
